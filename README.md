# NX Infinity

Windows downloads, API source and Linux/Proton information.

Download the Windows ZIP from [Releases](https://github.com/coye2/NX-Infinity-Releases/releases) once published, extract the entire archive, and run **NX Infinity.exe**. Keep the cores and supporting folders beside it. Games, keys, firmware and personal profiles are not included.

The candidate release is **1.0.0-beta.1**. Its recorded scope covers launch metadata, firmware imports, JIT/cache recovery, cover artwork, controller improvements, and four-core Windows packaging. Do not interpret the candidate as Beta 2 or as a promise of unfinished features. Nextendo account sign-in is separate from native online gameplay; native Nextendo gameplay integration is unfinished. Actual compatibility varies by core and game.

Only the MIT-licensed NX API is intended for the standalone source export here. This public repository contains no emulator implementation source or private development history. Third-party runtime notices and corresponding-source requirements must be resolved before publishing the Windows binary.
