# NX Infinity

Windows downloads, API source and Linux/Proton information.

Download the Windows ZIP from [Releases](https://github.com/coye2/NX-Infinity-Releases/releases), extract the entire archive, and run **NX Infinity.exe**. Keep the cores and supporting folders beside it. Games, keys, firmware and personal profiles are not included.

The application includes Kenji/Ryujinx, Ryujinx Canary, Eden and Citron cores. Beta 2 adds Theme Studio, clearer Settings values, local profile avatars, controller remapping and collection-program transition handling. Nextendo account sign-in is separate from native online gameplay; the native Nextendo gameplay integration is unfinished. Actual compatibility varies by core and game.

Only the MIT-licensed NX API is distributed as a source export here. This repository contains no emulator implementation source or private development history. Component license notices are retained in the application archive.
